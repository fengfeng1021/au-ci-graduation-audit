# 畢業審查工具

**▶ 線上直接使用（免安裝、免登入）：<https://fengfeng1021.github.io/au-ci-graduation-audit/>**

畢業學分**自我檢核**小工具。勾選自己修過的課，就即時算出各分類進度與畢業結論。
內建亞洲大學資訊傳播學系 112 學年課綱；**其他系所可以自己匯入課綱**，工具本身是通用的。

> 給同學用的版本：純網頁、**不需要登入、不經過任何 AI、沒有後端伺服器**。
> 你的勾選資料只會存在自己這台裝置的瀏覽器裡。

## 功能

- **課程勾選即時試算**：院核心 / 系核心 / 主修學程 / 通識 / 自由選修分別計算，合計對照畢業門檻。
- **主修學程二選一**：一鍵切換，清單跟著換。
- **跨學程折抵（雙向）**：折抵方向跟著你的主修走。主修新媒體，就用智慧學程的課折抵；主修智慧，就用新媒體的課折抵（**折抵規則以系辦認定為準**）。
- **超修不灌總分**：每個分類最多採計應修學分，超修的部分會提示你改計自由選修，避免誤判「可以畢業」。
- **一眼看出還缺什麼**：畢業結論下方直接列出未達標的分類與未通過的門檻。
- **一鍵全選 / 清空本區**：整區課程快速勾選，不用一門一門點。
- **貼上成績單自動勾選**：把歷年成績整段貼上，在本機比對課名／課號自動打勾。停修、退選、不及格（<60）會自動略過，並列出「已勾選」與「未勾選」明細讓你核對。
- **畢業門檻檢定**：中文、英文、資訊、服務學習、體育等，通過打勾。
- **列印 / 存 PDF**：專用列印樣式，印出來是一份可以帶去系辦談的檢核表。
- **換一份課綱**：見下方「給其他系所的同學」。

## 使用方式

1. 直接開網站，或把整個資料夾下載後用瀏覽器開 `index.html`。
2. 勾選你已經**及格**的課；或點「貼上成績單自動勾選」貼上成績一次搞定。
3. 「通識」「自由選修」的學分，因為每個人修的不同，請看成績單自行加總後填入。
4. 上方會即時顯示「還差幾學分」與畢業結論。

## 給其他系所的同學

課綱是一份**可替換的資料**，不用改程式就能換成你們系的。在網站下方打開「換一份課綱」面板，有三種方式：

1. **貼課表文字**：照下面格式貼上，按「由課表文字產生 JSON」，確認後匯入。
2. **匯入 JSON 檔**：直接選一個課綱 JSON 檔。
3. **匯出現有課綱當範本**：下載目前這份 JSON，改成你們系的再匯入。

課表文字格式（每行一項）：

```
@meta 亞洲大學 | 資訊傳播學系 | 112 學年入學 | 128
@group 院核心 | 9 | checklist
ES300208 基礎程式設計(一) 1
EP300355 人工智慧與雲端應用 3
@group 主修學程 | 27 | choice
@option 新媒體傳播內容學程
EP300329 傳播敘事與劇本創作 2
@option 智慧傳播應用學程
EP300361 資訊視覺化 3
@group 校定必修通識 | 30 | credits
@group 自由選修 | 23 | credits
@threshold 中文能力檢定
@threshold 英文能力檢定
```

- `@group` 的類型有三種：`checklist` 逐門勾選（必修）、`credits` 直接填學分（通識、自由選修）、`choice` 學程擇一。
- 課程行寫成 `課號 課名 學分`，課號可省略，空白或 Tab 分隔都可以。
- 各分類「應修學分」加總必須等於畢業總學分，不符會直接提醒你。

也可以用命令列轉換（需要 Node.js）：

```bash
node tools/make-curriculum.mjs 課表.txt > 我的系.json
```

### 關於「直接丟課綱 PDF」

**實測結果：亞大這批課程規劃表 PDF 抽不出中文。** 用 `pdftotext` 兩種模式測，中文字元數都是 0，
只有英文課名和數字出得來。原因是 PDF 內嵌字型沒有 ToUnicode 對照表，文字複製出來是空的。

所以最省事的做法是**從網頁版課程規劃表複製表格文字**（HTML 的中文可以正常複製），
再照上面的格式整理。`tools/make-curriculum.mjs` 也接受 PDF，但遇到抽不出中文時會直接告訴你，
不會默默產生一份空的課綱。

## 隱私

- 所有資料只存在瀏覽器的 `localStorage`，**不會上傳到任何伺服器**，關掉分頁再打開還在。
- 換裝置、換瀏覽器或清除瀏覽資料，紀錄就會消失（本工具不做雲端同步，正是為了不碰你的個資）。
- 這個專案裡**不包含任何人的成績或身分資料**，只有通用的課綱結構。

## 重要聲明

本工具僅供**自我檢核參考**。折抵、學程最低門檻、抵免、實習學分等**實際認定，一律以系辦與教務處公告為準**。
畢業前請務必與系辦當面確認。若你發現課綱資料有誤，歡迎回報或直接改 `curriculum.js`。

## 技術

- 純前端：HTML + CSS + 原生 JavaScript，無框架、無建置步驟。
- 動效：[GSAP](https://gsap.com/)，依官方規範實作——`gsap.matchMedia()` 處理 `prefers-reduced-motion`、
  `gsap.defaults()` 統一節奏、`gsap.quickTo()` 處理高頻更新的學分讀數與進度條、
  `timeline` 編排多步動畫、進度條用 `scaleX` 而非 `width` 以避免觸發 layout。
- 設計系統：色彩／字級／間距／圓角／陰影 tokens 集中定義，元件（進度儀表、課程列、徽章、分段控制…）一次設計、全站重用。
- 字體：Noto Serif TC（標題與結論）＋ Noto Sans TC（內文與介面）。
- 無障礙：所有文字對比皆 ≥ 4.5:1，鍵盤可完整操作，裝飾性元件標記 `aria-hidden`。

## 檔案結構

```
index.html                  介面結構 + SVG 圖示
styles.css                  設計系統（tokens + 元件樣式 + 列印樣式）
curriculum.js               課綱資料（可替換；格式說明寫在檔案開頭）
app.js                      計算邏輯 + 成績單解析 + GSAP 動效
tools/make-curriculum.mjs   課表文字 / PDF → 課綱 JSON 轉換腳本
```
