# 資傳系畢業審查工具 · 112 課綱

**▶ 線上直接使用（免安裝、免登入）：<https://fengfeng1021.github.io/au-ci-graduation-audit/>**

亞洲大學資訊傳播學系（112 學年入學適用）的畢業學分**自我檢核**小工具。
勾選自己修過的課，就即時算出院核心、系核心、主修學程、通識自由的進度，並給出畢業結論。

> 給同學用的版本：純網頁、**不需要登入、不經過任何 AI、沒有後端伺服器**。
> 你的勾選資料只會存在自己這台裝置的瀏覽器裡。

## 功能

- **課程勾選即時試算**：院核心 9 / 系核心 39 / 主修學程 27 / 校定必修通識 30 / 自由選修 23，合計畢業門檻 128 學分。
- **主修學程二選一**：智慧傳播應用學程 ↔ 新媒體傳播內容學程，一鍵切換。
- **智慧課折抵新媒體**：選新媒體為主修時，可勾選已修過的智慧學程課程折抵 27 學分（**折抵規則以系辦認定為準**）。
- **貼上成績單自動勾選**：把學生資訊系統的歷年成績整段貼上，工具在本機比對課名／課號自動打勾；停修、不及格（<60）會自動略過，對不到的通識／自由選修會列出來提醒你手動加總。
- **畢業門檻檢定**：中文、英文、資訊、服務學習、體育四學期，通過打勾。
- **列印 / 存 PDF**：一鍵輸出目前檢核結果。

## 使用方式

1. 直接開網站（GitHub Pages），或把整個資料夾下載後用瀏覽器開 `index.html`。
2. 勾選你已經**及格**的課；或點「貼上成績單自動勾選」貼上成績一次搞定。
3. 「校定必修·通識」「自由選修」的學分，因為每個人修的通識不同，請看成績單自行加總後填入。
4. 上方會即時顯示「還差幾學分」與畢業結論。

## 隱私

- 所有資料只存在瀏覽器的 `localStorage`，**不會上傳到任何伺服器**，關掉分頁再打開還在。
- 換裝置、換瀏覽器或清除瀏覽資料，紀錄就會消失（本工具不做雲端同步，正是為了不碰你的個資）。
- 這個專案裡**不包含任何人的成績或身分資料**，只有通用的課綱結構。

## 重要聲明

本工具依 **112 學年課綱**整理，僅供**自我檢核參考**。
折抵、學程最低門檻、抵免、實習學分等**實際認定，一律以系辦與教務處公告為準**。
畢業前請務必與系辦當面確認。若你發現課綱資料有誤，歡迎回報或直接改 `curriculum.js`。

## 技術

- 純前端：HTML + CSS + 原生 JavaScript，無框架、無建置步驟。
- 動效：[GSAP](https://gsap.com/)（透過 CDN 載入）。
- 設計系統：色彩／字級／間距／圓角／陰影 tokens 集中定義，元件（進度儀表、課程列、徽章、分段控制…）一次設計、全站重用。
- 字體：Noto Serif TC（標題與結論）＋ Noto Sans TC（內文與介面）。
- 尊重 `prefers-reduced-motion`，會自動關閉位移動畫。

## 檔案結構

```
index.html      介面結構 + SVG 圖示
styles.css      設計系統（tokens + 元件樣式）
curriculum.js   112 課綱資料（純資料，可自行維護更新）
app.js          計算邏輯 + GSAP 動效
```

## 在本機預覽

因為用到 `fetch` 之外的相對路徑載入，直接雙擊 `index.html` 多數情況也可運作；
若遇到瀏覽器限制，可在資料夾內起一個簡單的本機伺服器：

```bash
python -m http.server 8123
```

然後開 `http://localhost:8123`。
